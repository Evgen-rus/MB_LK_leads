## Промпт для Cursor (gpt-5.2-codex)

Нужно сделать отдельный минимальный скрипт на FastAPI для приема тестовых лидов от провайдера.
Текущий проект на сервере (FastAPI + PostgreSQL), но основное приложение трогать нельзя.
Провайдер умеет отправлять только вебхук, т.е. можно указать только одну API-ссылку.
Нужен отдельный мини-сервер с одним POST-endpoint, который:
- принимает JSON (или form-data, если пришло),
- выводит тело запроса в лог/файл,
- возвращает 200 OK.

Формат данных примерно такой:
- vid, site, page, ref, browser, device, platform, ip, comment, roistat_visit
- phones: массив строк
- mails: массив строк
- utm: объект с utm_* и gclid

Сделай:
1) файл `webhook_test.py` с минимальным FastAPI-приложением,
2) команду запуска uvicorn,
3) короткую инструкцию, как проксировать через Nginx (например `https://мой-домен.ru/api/provider-test` → `http://127.0.0.1:8005/api/provider-test`),
4) куда будет сохраняться лог (например `logs/provider_webhook.log`).

Важно: без подключения к БД, просто лог и ответ 200.
Если возможно, добавь защиту простым "секретом" в URL (например `/api/provider-test/<secret>`).
Если провайдер не принимает URL с секретом, объясни альтернативу: ограничение по IP на Nginx.
