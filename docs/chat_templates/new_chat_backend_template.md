# Шаблон нового чата — Backend

Скопируй и заполни:

```text
Новая задача (backend):
<кратко: что нужно получить в итоге>

Контекст:
- Прочитай @ARCHITECTURE.md
- Работать только в: @backend/app/...
- Не трогать: <перечень файлов/зон, если есть>

Что сделать:
1) <шаг 1>
2) <шаг 2>
3) <шаг 3>

Ограничения:
- Сохранить текущий API-контракт (если не оговорено обратное).
- Не добавлять лишние зависимости без необходимости.
- Учитывать роли/авторизацию и текущую бизнес-логику.

Критерии готовности:
- <ожидаемое поведение API/логики>
- <какие кейсы должны корректно отрабатывать>

Проверка:
- Прогнать релевантные тесты (если есть).
- Запустить backend локально и проверить endpoint(ы).
- Кратко описать: как проверить руками.

Формат ответа:
- Кратко: что сделано
- Список измененных файлов
- Риски (low/medium/high)
```

Подсказка:
- `@ARCHITECTURE.md` лучше прикладывать ссылкой, а не вставлять текстом целиком.
