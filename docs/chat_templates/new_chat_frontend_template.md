# Шаблон нового чата — Frontend

Скопируй и заполни:

```text
Новая задача (frontend):
<кратко: что нужно получить в итоге>

Контекст:
- Прочитай @ARCHITECTURE.md
- Работать только в: @my-app-vite/src/...
- Не трогать: <перечень файлов/зон, если есть>

Что сделать:
1) <шаг 1>
2) <шаг 2>
3) <шаг 3>

Ограничения:
- Сохранить текущий стиль UI.
- Не ломать мобильную версию.
- Не менять API-контракты без согласования.

Критерии готовности:
- <что должно работать после правки>
- <что пользователь должен увидеть в интерфейсе>

Проверка:
- Прогнать: npm run build
- Если есть, прогнать: npm run test
- Написать, где проверить руками (экран/роль/путь)

Формат ответа:
- Кратко: что сделано
- Список измененных файлов
- Риски (low/medium/high)
```

Подсказка:
- `@ARCHITECTURE.md` прикладывать стоит (ссылкой, не копипастой), это экономит токены и ускоряет старт.
