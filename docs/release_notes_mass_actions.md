# Release Notes: Массовые действия в проектах

## Что добавлено

- Вкладка `Проекты` (клиентский ЛК): массовые действия по выбранным проектам.
- Выделение:
  - чекбокс в строке,
  - чекбокс в шапке таблицы (выбрать все на текущей странице),
  - удалённые проекты нельзя выделять.
- Панель массовых действий:
  - `Выбрано: N`,
  - `Снять выделение`,
  - меню `Массовые действия`.

## Доступные массовые операции

- Дни получения данных (полная замена набора дней).
- Лимит (полная замена числа).
- Телефоны/сайты конкурентов (полная замена списка).
- Регионы (полная замена списка).
- Статус проекта (`Активен` / `На паузе`).

## Важная логика применения

- Обновления отправляются **последовательно**: 1 проект = 1 запрос, ждём ответ, затем следующий.
- При ошибке одного проекта процесс продолжается для остальных.
- После выполнения показывается итоговый toast:
  - сколько обновлено,
  - сколько пропущено,
  - сколько с ошибкой,
  - поимённо: к каким проектам применено/не применено.

## Разделение по типам/режимам

- Телефоны/сайты:
  - при смешанном наборе источников выбирается целевая группа,
  - другая группа пропускается.
- Регионы:
  - при смешанном наборе режимов (`Включить` / `Исключить`) выбирается целевая группа,
  - в модалке явно показано, какие проекты будут изменены и какие нет,
  - в toast указывается причина пропуска: другой режим регионов.

## Ограничения

- Область выделения: только текущая страница.
- Удалённые проекты недоступны для массового редактирования.
- Массовый перевод в `Удалён` не поддерживается.
