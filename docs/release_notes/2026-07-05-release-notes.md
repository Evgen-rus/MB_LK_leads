### Release Notes — 05.07.2026

Что сделали:

**Уведомления по тарифу**
- Было: клиент получал тарифные Telegram-сигналы только по заранее заданным порогам остатка.
- Стало: добавили системный сигнал, когда остаток клиента стал **0 или меньше**. Уведомление отправляется в Telegram, даже если баланс ушёл в минус.

**Создание клиента в админке**
- Было: после создания нового клиента иногда открывалась сводка другого клиента.
- Стало: после создания открывается сводка именно того клиента, которого только что создали.

**Фильтр ТОП-проектов**
- Было: проекты можно было отмечать звёздочкой, но быстро отфильтровать только ТОП было нельзя.
- Стало: добавили кнопку **★** рядом с фильтром **100%**. Она показывает только ТОП-проекты. Активное состояние подсвечивается.

**Статус проекта**
- Было: при клике по статусу проекта было непонятно, выполняется действие или нет.
- Стало: добавили анимацию загрузки на статус. Пока статус обновляется, повторный клик по этому же проекту блокируется.

**Массовые действия для проектов с блокировкой оператора**
- Было: проекты со статусом **«Блокировка оператора»** нельзя было выбрать для массовых действий.
- Стало: такие проекты можно массово перевести в другой статус или удалить. Для остальных массовых действий показываем понятное предупреждение.

**Настройка гео**
- Было: регионы приходилось выбирать по одному, что неудобно для больших списков.
- Стало: добавили вставку списка регионов. Можно вставить регионы строками или через запятую, найденные регионы добавятся автоматически, ненайденные будут показаны отдельно.
- Также добавили копирование списка регионов из другого проекта этого же клиента. Копируется только список регионов, режим **Включить/Исключить** не меняется.

**Создание проекта в клиентском ЛК**
- Было: при каждом открытии модалки создания проекта настройки снова были дефолтными.
- Стало: после успешного создания запоминаются последние настройки: источник сбора, лимит, статус, гео, дни и выбранные источники A/B/C/D. При следующем создании они подставляются автоматически.
- Добавили кнопку **«Сбросить настройки»**, чтобы быстро вернуться к значениям по умолчанию.
