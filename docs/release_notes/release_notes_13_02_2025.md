# Release Notes — 13.02.2025

## Кратко

- На фронтенде дублирован блок пагинации: теперь он есть **сверху и снизу** таблиц.
- Внешний вид пагинации сохранен в текущем стиле проекта.
- Добавлена адаптация для мобильной версии: блок не съезжает и корректно переносится.

## Где уже работает

- Клиентский ЛК:
  - `Проекты`
  - `Идентификации`
  - `Отчёты`
  - `Черный список`
  - `Баланс` (таблица операций)
- Админский ЛК:
  - `Клиенты`
  - `Проекты клиента`
  - `Идентификации`
  - `Отчёты`
  - `Черный список`
  - `Баланс` (таблица операций)

## Польза для заказчика

- Меньше лишней прокрутки: переход по страницам доступен сразу сверху.
- На мобильных устройствах навигация по страницам стала стабильнее и удобнее.

## Дополнительно (вкладка «Проекты»)

- По клику на название проекта теперь открывается меню действий, а не мгновенный переход.
- Пункты меню в клиентском ЛК:
  - `Настройки проекта`
  - `Идентификации проекта`
  - `История изменений`
  - `Удаление проекта`
- Пункты меню в админском ЛК:
  - `Настройки проекта`
  - `Идентификации проекта`
  - `История изменений`
  - Пункт удаления в меню для админа скрыт.

## UX-улучшения меню проекта

- Меню открывается справа от названия проекта и не перекрывается содержимым таблицы.
- Пока меню открыто, клик вне меню просто закрывает его (без обязательного выбора пункта).
- Клики и hover не «проваливаются» в элементы под меню.
- Меню автоматически закрывается при прокрутке страницы/таблицы и при изменении размера окна.

## Идентификации (клиентский ЛК)

- Для пустого результата добавлен явный текст в таблице:
  - `По выбранным фильтрам идентификаций не найдено.`
- Это снижает неопределенность для пользователя, когда данные отсутствуют из-за фильтров/периода.
- В фильтре `Проекты` добавлен текстовый поиск по ID/названию:
  - можно быстро найти проект без долгой прокрутки списка;
  - выбор по чекбоксам сохранен;
  - при отсутствии совпадений показывается подсказка `По запросу ничего не найдено`.
- В списке фильтра `Проекты` скрыт ID — отображается только название проекта.
- Обновлен порядок столбцов в таблице:
  1. `Дата`
  2. `Проект`
  3. `Канал`
  4. `Источник`
  5. `Телефон`

## Идентификации (админский ЛК)

- В списке фильтра `Проекты` скрыт ID — отображается только название проекта.
- Обновлен порядок столбцов в таблице:
  1. `Дата`
  2. `Проект`
  3. `Канал`
  4. `Источник`
  5. `Телефон`
  6. `ext_id`
  7. `Клиент`

## Админский ЛК (вкладка «Клиенты»)

- В строке клиента добавлена кнопка `Перейти в ЛК`.
- Кнопка позволяет быстро открыть ЛК выбранного клиента напрямую из таблицы клиентов.
