# Release Notes — 08.05.2026

## Кратко

- Для лидов провайдера добавлен внутренний публичный идентификатор **lk id**.
- `lk id` считается без изменения БД по формуле `30100000 + provider_leads.id`.
- В клиентском и админском ЛК `lk id` теперь показывается в таблицах идентификаций.
- В скачиваемые отчёты CSV/XLSX добавлена колонка `lk id`.
- Экспорт provider leads в Google Sheets расширен до диапазона `A:H`; новая колонка `H` содержит `lk id`.
- Provider `vid` / `ext_id` сохранён и продолжает использоваться для сверки с провайдером.

## Что изменено

### lk id для лидов

- Добавлен единый helper `format_provider_lead_lk_id`, который формирует значение `lk id`.
- Значение не хранится отдельной колонкой в БД, а вычисляется при формировании API-ответов и экспортов.
- Это скрывает прямой автоинкрементный `provider_leads.id`, но сохраняет возможность внутренней сверки.

### UI

- В клиентской таблице лидов добавлена колонка:
  - `Дата | Телефон | Канал | Источники | Проект | lk id`
- В админской таблице лидов добавлена колонка перед `ext_id`:
  - `Дата | Телефон | Канал | Источники | Проект | lk id | ext_id | Клиент`
- `ext_id` у администратора оставлен видимым: это по-прежнему `vid` провайдера.

### Отчёты CSV/XLSX

- В endpoint `/leads/export` добавлено поле `lk id` для обоих форматов.
- Клиентский файл теперь содержит:
  - `Дата | Телефон | Канал | Источники | Проект | lk id`
- Админский и агентский файл теперь содержит:
  - `Дата | Телефон | Канал | Источники | Проект | lk id | ext_id | Клиент`

### Google Sheets export

- `tool_export_provider_leads.py` теперь заполняет диапазон `A:H`.
- Новая колонка:
  - `H lk id -> 30100000 + provider_leads.id`
- Остальные колонки `A:G` не менялись.

## Технически

- `backend/app/provider_lead_ids.py`: общий helper и offset для `lk id`.
- `backend/app/schemas.py`: `lk_id` добавлен в `LeadOut` и `AdminLeadOut`.
- `backend/app/crud.py`: `lk_id` добавлен в клиентские/админские списки лидов и строки экспортов.
- `backend/app/main.py`: `lk id` добавлен в CSV/XLSX отчёты `/leads/export`.
- `my-app-vite/src/api.ts`: типы `Lead` и `AdminLead` расширены полем `lk_id`.
- `my-app-vite/src/components/LeadsTable.tsx`: колонка `lk id` в клиентской таблице.
- `my-app-vite/src/components/AdminLeadsTable.tsx`: колонка `lk id` в админской таблице.
- `tool_export_provider_leads.py`: экспорт в Google Sheets расширен до `A:H`.
- Проверки: `python -m py_compile` для изменённых backend/CLI-файлов, `npm.cmd run build`.
