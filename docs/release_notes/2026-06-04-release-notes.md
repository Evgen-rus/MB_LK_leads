## Текст для Telegram заказчика без лишних тех. деталей:

### Release Notes — 04.06.2026

Сегодня улучшили проверку D-проектов и уведомления о блокировке оператором.

Что сделали:

- Если поставщик вернул пустой ответ по D-проекту, ЛК теперь переводит такой проект в статус **Блокировка оператора**, как и при явном отключении проекта у поставщика.
- Для таких случаев добавили понятное Telegram-уведомление: **Пустой ответ, нужна доп проверка админом**.
- В уведомлении показываются клиент, проект, ID проекта и триггер проверки, чтобы администратору было проще быстро найти и проверить проект.
- В истории проекта теперь сохраняется понятная причина: поставщик вернул пустой ответ по проекту при проверке D.
- Сетевые ошибки и временные сбои поставщика по-прежнему не переводят проекты в блокировку автоматически.

Теперь спорные D-проекты не остаются незамеченными: они фиксируются в ЛК, попадают в историю и сопровождаются понятным уведомлением для администратора.
