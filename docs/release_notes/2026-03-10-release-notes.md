# Release Notes — 10.03.2026

## Кратко

- **Telegram-уведомления клиентам** — единая система: автопауза по лимитам и новые уведомления по остатку (3/2/1 день, остаток закончился).
- **Персональный Telegram-чат**: уведомления можно направлять в отдельную группу для каждого клиента. В карточке клиента — поля **Telegram chat ID** и галочка **«Использовать этот чат для уведомлений»**.
- **Уведомления по остатку**: при достижении порогов (остатка хватит на 3/2/1 день или остаток закончился) отправляется сообщение в момент наступления события. Расчёт по лимитам включённых проектов. Защита от дублей: повторная отправка только после выхода из опасной зоны и повторного входа.
- При первом включении маршрута или смене chat id отправляется **тестовое сообщение** — сразу видно, что настройка работает.
- Отключены батч-уведомления по изменениям проектов и чёрного списка. В Telegram остаются: автопауза, уведомления по остатку и сообщения из формы поддержки.

## Где работает

- Backend / API:
  - поля в `users`: `telegram_notifications_chat_id`, `telegram_auto_pause_enabled`, `telegram_balance_alert_level`;
  - единая маршрутизация уведомлений: если у клиента включён персональный маршрут и задан chat id — отправка туда, иначе fallback на глобальный `TELEGRAM_CHAT_ID`;
  - уведомления по остатку: проверка при изменении баланса, лимитов проектов, создании/удалении проектов, массовой паузе/восстановлении; расчёт `remaining / сумма_лимитов_активных_проектов`;
  - тестовое сообщение при сохранении карточки клиента, если галочка включена впервые или изменился chat id;
  - при неудачной отправке теста настройки не сохраняются, админ видит ошибку.
- Личный кабинет:
  - карточка клиента (`AdminClientCardModal`) — блок «Telegram для уведомлений» с полем chat id и чекбоксом;
  - экран «Клиенты» — при открытии карточки подставляются текущие значения.

## Что изменено

### Backend

- Поля в `User`: `telegram_notifications_chat_id`, `telegram_auto_pause_enabled`, `telegram_balance_alert_level` (последний отправленный порог по остатку).
- Функция `_get_client_telegram_chat_id_for_notifications`: единый выбор чата для всех системных уведомлений (клиентский или глобальный).
- Уведомления об автопаузе и по остатку используют персональный чат клиента, если маршрут включён и chat id задан.
- **Уведомления по остатку**: пороги 3/2/1 день и «остаток закончился»; расчёт по `remaining / сумма_лимитов_активных_проектов`; проверка при изменении баланса, проектов, массовой паузе/восстановлении; защита от дублей через `telegram_balance_alert_level`.
- При обновлении карточки клиента: если маршрут включён впервые или изменился chat id — отправка тестового сообщения; при ошибке — rollback и понятная ошибка в API.
- Отключена отправка в Telegram сводок по audit_events (создание/изменение/удаление проектов, изменения чёрного списка). Воркер `notify_worker` по-прежнему закрывает debounce-очередь, но сообщения не формирует.
- Schema-evolution: новые колонки добавляются автоматически при старте backend.

### Frontend

- `AdminClientCardModal`:
  - блок «Telegram для уведомлений» с полем chat id и чекбоксом;
  - подсказка: при пустом chat id или выключенном маршруте уведомления уходят в общий чат.
- `AdminClientsScreen`: при открытии карточки передаются `telegramNotificationsChatId` и `telegramAutoPauseEnabled`.
- Обновлены типы API: `AdminClientCreatePayload`, `AdminClientUpdatePayload`, `UserInfo`, `MeResponse`.

## Поведение для админа

- В карточке клиента можно указать Telegram chat id группы и включить маршрут уведомлений (автопауза + остаток).
- При первом включении галочки или смене chat id при сохранении уходит тестовое сообщение. Если отправка не удалась — настройки не сохраняются, показывается ошибка.
- Если chat id не задан или маршрут выключен — уведомления уходят в общий чат из `TELEGRAM_CHAT_ID`.

## Польза для заказчика

- Уведомления (автопауза и остаток) можно направлять в отдельную группу по каждому клиенту.
- Клиент заранее узнаёт, когда остатка хватит на 3/2/1 день или когда остаток закончился — можно пополнить баланс до автопаузы.
- Тестовое сообщение сразу подтверждает, что chat id и бот настроены верно.
- Меньше шума в общем чате: сводки по изменениям проектов и ЧС больше не отправляются в Telegram.
