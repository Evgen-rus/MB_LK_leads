# Release Notes — 10.03.2026

## Кратко

- **Персональный Telegram-чат для автопаузы по лимитам**: уведомления об автопаузе можно направлять в отдельную группу для каждого клиента.
- В карточке клиента добавлены поля: **Telegram chat ID** и галочка **«Использовать этот чат для уведомлений об автопаузе»**.
- При первом включении маршрута или смене chat id отправляется **тестовое сообщение** в указанный чат — сразу видно, что настройка работает.
- Отключены батч-уведомления в Telegram по изменениям проектов и чёрного списка. В Telegram остаются только: автопауза по лимитам и сообщения из формы поддержки.

## Где работает

- Backend / API:
  - новые поля в `users`: `telegram_notifications_chat_id`, `telegram_auto_pause_enabled`;
  - логика маршрутизации автопаузы: если у клиента включён персональный маршрут и задан chat id — отправка туда, иначе fallback на глобальный `TELEGRAM_CHAT_ID`;
  - тестовое сообщение при сохранении карточки клиента, если галочка включена впервые или изменился chat id;
  - при неудачной отправке теста настройки не сохраняются, админ видит ошибку.
- Личный кабинет:
  - карточка клиента (`AdminClientCardModal`) — блок «Telegram для автопаузы по лимитам» с полем chat id и чекбоксом;
  - экран «Клиенты» — при открытии карточки подставляются текущие значения.

## Что изменено

### Backend

- Добавлены поля `telegram_notifications_chat_id` и `telegram_auto_pause_enabled` в модель `User`.
- Реализована функция `_get_client_telegram_chat_id_for_auto_pause`: выбор чата для автопаузы (клиентский или глобальный).
- Уведомление об автопаузе теперь использует персональный чат клиента, если маршрут включён и chat id задан.
- При обновлении карточки клиента: если маршрут включён впервые или изменился chat id — отправка тестового сообщения; при ошибке — rollback и понятная ошибка в API.
- Отключена отправка в Telegram сводок по audit_events (создание/изменение/удаление проектов, изменения чёрного списка). Воркер `notify_worker` по-прежнему закрывает debounce-очередь, но сообщения не формирует.
- Schema-evolution: новые колонки добавляются автоматически при старте backend.

### Frontend

- `AdminClientCardModal`:
  - блок «Telegram для автопаузы по лимитам» с полем chat id и чекбоксом;
  - подсказка: при пустом chat id или выключенном маршруте автопауза уходит в общий чат.
- `AdminClientsScreen`: при открытии карточки передаются `telegramNotificationsChatId` и `telegramAutoPauseEnabled`.
- Обновлены типы API: `AdminClientCreatePayload`, `AdminClientUpdatePayload`, `UserInfo`, `MeResponse`.

## Поведение для админа

- В карточке клиента можно указать Telegram chat id группы и включить маршрут автопаузы.
- При первом включении галочки или смене chat id при сохранении уходит тестовое сообщение. Если отправка не удалась — настройки не сохраняются, показывается ошибка.
- Если chat id не задан или маршрут выключен — автопауза продолжает уходить в общий чат из `TELEGRAM_CHAT_ID`.

## Польза для заказчика

- Уведомления об автопаузе можно направлять в отдельную группу по каждому клиенту.
- Тестовое сообщение сразу подтверждает, что chat id и бот настроены верно.
- Меньше шума в общем чате: сводки по изменениям проектов и ЧС больше не отправляются в Telegram.
