# Release Notes — 17.02.2025

## Кратко

- При создании проекта в модалке **«Создать проект»** блок **«Дни сбора»** по умолчанию теперь выставляет все 7 дней недели (Пн–Вс) вместо прежних рабочих дней (Пн–Пт).

## Где работает

- Клиентский ЛК: кнопка **Создать проект** → модальное окно создания проекта → секция **Дни сбора**.

## Изменение «Дни сбора» по умолчанию

- **Было:** при открытии формы создания проекта по умолчанию отмечены 5 дней: Пн, Вт, Ср, Чт, Пт.
- **Стало:** по умолчанию отмечены все 7 дней: Пн, Вт, Ср, Чт, Пт, Сб, Вс.

Пользователь по-прежнему может снять или добавить любые дни вручную. Изменение затрагивает только начальное состояние чекбоксов при открытии формы.

## Польза для заказчика

- Меньше ручных действий при создании проектов, где нужен сбор данных все семь дней.
- Соответствие ожиданию «по умолчанию — все дни», зафиксированному в требованиях.
