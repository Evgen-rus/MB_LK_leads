# Release Notes — 17.02.2025

## Кратко

- При создании проекта в модалке **«Создать проект»** блок **«Дни сбора»** по умолчанию теперь выставляет все 7 дней недели (Пн–Вс) вместо прежних рабочих дней (Пн–Пт).
- Унифицировано отображение **даты и времени** во всех таблицах и карточках/модалках с датой: теперь формат компактный, в две строки.
- Обновлён вывод **периода** в отчётах и сводках баланса/клиентов: вместо сырого `YYYY-MM-DD — YYYY-MM-DD` используется компактный формат с русскими месяцами.

## Где работает

- Клиентский ЛК: кнопка **Создать проект** → модальное окно создания проекта → секция **Дни сбора**.
- Клиентский ЛК: таблицы **Проекты / Идентификации / Отчёты / Баланс / Чёрный список**, модалки истории/карточек проекта.
- Админский ЛК: таблицы **Клиенты / Проекты клиента / Изменения клиента / События ЧС / Идентификации / Отчёты / Баланс / Чёрный список**, модалка истории проекта.

## Изменение «Дни сбора» по умолчанию

- **Было:** при открытии формы создания проекта по умолчанию отмечены 5 дней: Пн, Вт, Ср, Чт, Пт.
- **Стало:** по умолчанию отмечены все 7 дней: Пн, Вт, Ср, Чт, Пт, Сб, Вс.

Пользователь по-прежнему может снять или добавить любые дни вручную. Изменение затрагивает только начальное состояние чекбоксов при открытии формы.

## Новый формат даты и времени

Теперь дата/время отображаются компактно:

```text
17 фев
04:42
```

Правила:

- 1-я строка: `день + сокращённый месяц` (русские сокращения: `янв, фев, мар, апр, май, июн, июл, авг, сен, окт, ноя, дек`).
- Год добавляется только для прошлых лет: например `17 фев 2025`.
- 2-я строка: только `HH:mm` (секунды не отображаются).
- Если в исходной строке времени нет, вторая строка скрывается.
- Если строка даты не распарсилась, отображается исходное значение (для упрощения диагностики).

## Новый формат периода

Периоды в отчётах и сводках приведены к компактному виду:

- один день: `16 фев` (или `16 фев 2025` для прошлых лет);
- диапазон в одном месяце: `16-20 фев`;
- диапазон в одном году, но разных месяцах: `28 фев - 3 мар`;
- диапазон в разных годах: `30 дек 2025 - 2 янв 2026`.

Обновлено в:

- таблицах **Отчёты** (клиент и админ);
- сводке **Баланс** (клиент и админ);
- строке периода в тулбаре экрана **Клиенты** (админ).

## Польза для заказчика

- Меньше ручных действий при создании проектов, где нужен сбор данных все семь дней.
- Соответствие ожиданию «по умолчанию — все дни», зафиксированному в требованиях.
- Компактная дата/время снижает ширину колонки и ускоряет чтение таблиц.
- Периоды в интерфейсе стали человеко-понятными без технического ISO-формата.
