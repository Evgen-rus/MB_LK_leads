# Release Notes — 17.02.2025

## Кратко

- В модалке **«Создать проект»** блок **«Дни сбора»** по умолчанию теперь отмечает все 7 дней недели (Пн–Вс).
- Унифицировано отображение **даты и времени** во всех таблицах и карточках/модалках с датой: компактный формат в 2 строки.
- Обновлён вывод **периода**: вместо сырого `YYYY-MM-DD — YYYY-MM-DD` используется человеко-понятный компактный формат с русскими месяцами.
- Добавлена **история действий клиента**: колокольчик рядом с `Выйти` (последние 20 событий) и отдельная страница **«История изменений»**.
- История агрегирует события по аккаунту клиента из нескольких источников: проекты, чёрный список, баланс, отчёты.
- Исправлено дублирование отчётов при экспорте из раздела `Идентификации`: одно действие создаёт одну запись в списке отчётов и в истории.

## Где работает

- Клиентский ЛК: модалка создания проекта (`Дни сбора`).
- Клиентский ЛК: таблицы **Проекты / Идентификации / Отчёты / Баланс / Чёрный список**, а также карточки/модалки с датами.
- Админский ЛК: таблицы с датами и периодами (**Клиенты / Проекты клиента / Изменения клиента / События ЧС / Идентификации / Отчёты / Баланс / Чёрный список**).
- Клиентский ЛК: кнопка-колокольчик в правом верхнем углу + страница **«История изменений»**.

## Изменение «Дни сбора» по умолчанию

- **Было:** в форме создания проекта отмечались только рабочие дни (Пн–Пт).
- **Стало:** по умолчанию отмечаются все дни (Пн–Вс).

Пользователь по-прежнему может вручную изменить любой набор дней перед сохранением проекта.

## Новый формат даты и времени

Формат вывода:

```text
17 фев
04:42
```

Правила:

- 1-я строка: `день + сокращённый месяц` (`янв, фев, мар, апр, май, июн, июл, авг, сен, окт, ноя, дек`).
- Год показывается только если `year < текущий год`.
- 2-я строка: только `HH:mm` (секунды не показываются).
- Если времени нет в исходной строке, вторая строка скрывается.
- Если дата не распарсилась, показывается исходное значение (для диагностики).

## Новый формат периода

Периоды приведены к компактному виду:

- Один день: `16 фев` (или `16 фев 2025` для прошлых лет).
- Диапазон в одном месяце: `16-20 фев`.
- Диапазон в одном году, но в разных месяцах: `28 фев - 3 мар`.
- Диапазон в разных годах: `30 дек 2025 - 2 янв 2026`.

Обновлено в:

- Таблицах **Отчёты** (клиент и админ).
- Сводке **Баланс** (клиент и админ).
- Строке периода в тулбаре экрана **Клиенты** (админ).
- Тексте событий отчётов в **Истории изменений**.

## История действий (новый раздел)

### Что добавлено

- Кнопка-колокольчик рядом с `Выйти`.
- Dropdown с **последними 20 событиями**.
- Ссылка `Показать всю историю` с переходом на отдельную страницу истории.

### Что отображается в событии

- `ID события` (префикс источника, например `AE-*`, `BO-*`, `RE-*`).
- `Дата/время`.
- `Кто` выполнил действие (клиент/менеджер/админ/система).
- `Что сделано`.
- `Сущность` (проект / баланс / отчёт / ЧС).

### Какие события включены

- Проекты: создание/изменение/удаление.
- Баланс: начисление/списание.
- Отчёты: формирование (включая экспорт через `Идентификации`, без дублей).
- Чёрный список: добавление/удаление телефонов.

### Поведение и фильтры

- Данные подгружаются только по действию пользователя: при открытии колокольчика или страницы истории.
- На полной странице доступны фильтры по периоду, типу события и текстовый поиск.
- Пагинация полной истории: по 50 записей на страницу.
- Период по умолчанию на полной странице: последние 7 дней.

## Исправления по отчётам

- Возвращена запись событий по отчётам, сформированным через раздел `Идентификации`.
- Устранено двойное создание записей: теперь одно формирование/экспорт даёт одну запись в `Отчётах` и одну запись в истории.
- В тексте событий отчётов период выводится в том же компактном формате, что и в остальных разделах интерфейса.

## Польза для заказчика

- Быстрый визуальный аудит действий по аккаунту клиента без просмотра логов и кода.
- Более компактные таблицы и лучше читаемость даты/времени/периодов.
- Снижение риска путаницы в отчётах за счёт устранения дублей и единообразного формата отображения.
