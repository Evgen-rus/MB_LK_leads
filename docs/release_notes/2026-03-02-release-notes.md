# Release Notes — 02.03.2026

## Кратко

- Добавлен **автоматический контроль лимитов клиента**: система может сама ставить проекты на паузу, если сумма дневных лимитов активных проектов превышает остаток клиента.
- Режим **включается и выключается отдельно для каждого клиента** в админке. При выключении управление проектами остаётся полностью ручным.
- При попытке включить проект вручную (клиент или админ) сервер проверяет правило: если после включения сумма лимитов > остатка — операция блокируется с понятным сообщением.
- Клиент видит отдельное понятное объяснение при блокировке включения: что произошло и что сделать дальше (уменьшить лимиты или пополнить баланс).

## Где работает

- Backend / API:
  - новое поле `auto_limit_control_enabled` в `users` (пер-клиентный флаг);
  - проверка при включении проекта: `PATCH /projects/{project_id}`, `PATCH /admin/projects/{project_id}`;
  - проверка при массовом восстановлении: `POST /admin/clients/{client_id}/collection/resume`;
  - периодический воркер контроля лимитов (интервал через `AUTO_LIMIT_CHECK_SECONDS`, по умолчанию 300 с);
  - триггеры автопроверки: создание/обновление проектов, приход лида по webhook, операции с балансом.
- Личный кабинет:
  - экран админа (`AdminClientsScreen`) — кнопка «Включить/Выключить авто-контроль лимитов» и отображение текущего режима;
  - экран клиента (`ProjectsTable`) — понятное сообщение при блокировке включения проекта по лимитам.

## Что изменено

### Backend

- Добавлено поле `auto_limit_control_enabled` в модель `User` (по умолчанию `false`).
- Реализована логика авто-паузы:
  - расчёт остатка клиента (начисления − списания − фактическое использование по лидам);
  - расчёт суммы лимитов активных проектов;
  - при превышении: пауза проектов с наибольшими лимитами до соблюдения условия.
- Добавлена серверная проверка `can_activate_project_under_limit_control` при ручном включении проекта (клиент и админ).
- Уведомление в Telegram при автопаузе: список отключённых проектов, причина, шаги для восстановления.
- Переменная окружения `AUTO_LIMIT_CHECK_SECONDS` для интервала периодической проверки (по умолчанию 300).

### Frontend

- `AdminClientsScreen`:
  - кнопка переключения авто-контроля лимитов для выбранного клиента;
  - отображение режима: «автоматический + ручной» или «полностью ручной».
- `ProjectsTable`:
  - при ошибке `LIMIT_CONTROL_BLOCK` показывается отдельное понятное сообщение вместо общего alert;
  - текст объясняет причину блокировки и что сделать для включения проекта.

## Поведение для админа

- В карточке клиента можно включить или выключить авто-контроль лимитов одной кнопкой.
- При включении режима сразу выполняется проверка: если условие уже нарушено, часть проектов может быть автоматически поставлена на паузу.
- При массовом восстановлении проекты, для которых правило лимитов не выполняется, пропускаются с понятной причиной в списке ошибок.

## Польза для заказчика

- Система не допускает ухода в минус по остатку: сумма лимитов активных проектов всегда ≤ остатка клиента (при включённом режиме).
- Клиент и админ получают понятные подсказки при блокировке включения: что изменить и как восстановить работу.
- Гибкость: для части клиентов можно оставить полностью ручное управление, для других — включить авто-контроль.
