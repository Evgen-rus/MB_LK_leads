# Release Notes — 16.02.2025

## Кратко

- Изменён порядок пунктов в меню действий проекта: **«Идентификации проекта»** теперь идёт первым.
- В таблицах `Проекты` и `Идентификации` ID проекта теперь отображается рядом с названием в виде компактного бейджа.
- Уплотнена общая таблица: уменьшены вертикальные отступы строк и элементов, улучшена плотность интерфейса.
- На мобильных устройствах уменьшены размеры шрифтов таблиц для лучшей читаемости при плотной сетке.
- Кнопки в колонке `Действия` (📜 ⚙️ 🗑️) расположены компактнее.
- Разделение строк в таблицах сделано визуально явнее за счёт контура карточки строки.

## Где работает

- Клиентский ЛК: вкладка **Проекты**
- Админский ЛК: вкладка **Проекты клиента**
- Клиентский ЛК: вкладка **Идентификации**
- Админский ЛК: вкладка **Идентификации**
- Общие таблицы (глобальные стили `.table` в `App.css`)

## Изменение в меню проекта

При клике на название проекта открывается меню действий. Обновлённый порядок пунктов:

**Клиентский ЛК:**
1. `Идентификации проекта`
2. `Настройки проекта`
3. `История изменений`
4. `Удаление проекта`

**Админский ЛК:**
1. `Идентификации проекта`
2. `Настройки проекта`
3. `История изменений`

## Изменения в UI таблиц

### 1) Формат отображения ID проекта

- Было: `id` отдельной строкой под названием проекта.
- Стало: `id` отображается рядом с названием в одной строке (компактный бейдж).

### 2) Компактность таблиц

- Уменьшены вертикальные отступы ячеек таблицы (`td`).
- Уточнены `line-height` для основного и вторичного текста (`.name`, `.sub`).
- Уменьшены размеры бейджей (`.badge`) и служебных `id`-бейджей.

### 3) Мобильная плотность

- В `@media (max-width: 768px)` уменьшены размеры шрифтов и отступов в таблицах.
- Сохранена текущая логика горизонтального скролла для широких таблиц.

### 4) Колонка действий

- Кнопки `📜`, `⚙️`, `🗑️` сделаны компактнее (`icon-btn`).
- Уменьшен промежуток между кнопками в колонке `Действия`.

### 5) Визуальное разделение строк

- Добавлен явный мягкий контур карточки строки через `box-shadow` (в обычном и hover-состоянии).

## Польза для заказчика

- Самый частый переход — к идентификациям — доступен первым пунктом.
- Меньше лишних кликов при типичном сценарии работы с проектами.
- Таблицы стали плотнее: больше данных видно на экране без потери читаемости.
- Мобильная версия стала компактнее и удобнее для просмотра длинных таблиц.
- Действия по проекту считываются быстрее за счёт более плотного блока кнопок.
