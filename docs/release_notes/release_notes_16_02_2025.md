# Release Notes — 16.02.2025

## Кратко

- Изменён порядок пунктов в меню действий проекта: **«Идентификации проекта»** теперь идёт первым.

## Где работает

- Клиентский ЛК: вкладка **Проекты**
- Админский ЛК: вкладка **Проекты клиента**

## Изменение в меню проекта

При клике на название проекта открывается меню действий. Обновлённый порядок пунктов:

**Клиентский ЛК:**
1. `Идентификации проекта`
2. `Настройки проекта`
3. `История изменений`
4. `Удаление проекта`

**Админский ЛК:**
1. `Идентификации проекта`
2. `Настройки проекта`
3. `История изменений`

## Польза для заказчика

- Самый частый переход — к идентификациям — доступен первым пунктом.
- Меньше лишних кликов при типичном сценарии работы с проектами.
