## Текст для Telegram заказчика без лишних тех. деталей:

### Release Notes — 08.06.2026

Сегодня сделали удобнее работу с клиентами и проектами в админке, добавили графики и улучшили уведомления.

Что сделали:

**Карточка клиента в разделе «Клиенты»**
- Показываем, сколько данных в среднем приходит за **7 и 3 рабочих дня** (считаем рабочие дни с вторника по субботу).
- Видно, сколько данных за период пришло по каждому каналу **A / B / C / D**.
- Добавили **график за последние 30 дней** — сразу видна динамика.
- Кнопками **A / B / C / D** можно смотреть сводку сразу по нужным каналам или по всем вместе.

**Дашборд**
- Добавили показатели **«Среднее за 7 раб. дн.»** и **«Среднее за 3 раб. дн.»** — чтобы быстрее оценивать общую активность.
- По клику на **«Блокировки»** открывается **список всех D-проектов с блокировкой оператора**: клиент, проект, канал, когда обнаружили. Оттуда можно сразу перейти к проектам клиента.

**Графики по проектам**
- В админке и в клиентском ЛК у каждого проекта можно открыть **график данных** за выбранный период.
- На графике видно, сколько данных приходило по дням и из каких каналов **A / B / C / D**.

**Проекты клиента — массовые действия (только для администратора)**
- Можно **отметить несколько проектов** и одним действием изменить **дни**, **лимит**, **контакты**, **регионы**, **статус** или **удалить** проекты.
- Во время массового изменения видно, сколько проектов уже обработано.
- В массовый выбор **не попадают** проекты со статусами **«Блокировка оператора»** и **«Удалён»**.
- **Агент** по-прежнему видит проекты своих клиентов, но **массово менять и удалять** проекты не может.
- Добавили кнопку-фильтр **«Достигнут дневной лимит»** — показывает проекты, где за выбранный период уже набран полный дневной лимит.

**Telegram**
- Если проект **набрал 100% дневного лимита за сегодня**, в общий чат приходит уведомление с клиентом, проектом, каналом и цифрами. Повторно по тому же лимиту не дублируем; если лимит изменили — уведомление может прийти снова.
- В сообщениях о **низком остатке по тарифу** в общем чате теперь сразу видно **имя клиента**.
- В сообщениях о **начислениях и списаниях по тарифу** убрали лишнюю техническую строку — остались клиент, что сделали и на сколько.

**Если сервис временно недоступен**
- Вместо длинного технического текста показываем **понятное сообщение**: попробуйте ещё раз через 15 минут.
- При проблемах с **созданием или редактированием проектов** отдельно пишем, что временно недоступен **сервис поставщика**.

Теперь проще смотреть динамику по клиентам и проектам, быстрее находить блокировки и переполненные по лимиту проекты, массово обновлять настройки и понимать, что делать при временных сбоях.
