## Текст для Telegram заказчика без лишних тех. деталей:

### Release Notes — 08.06.2026

Сегодня улучшили аналитику по клиентам и проектам, добавили уведомления о дневном лимите и сделали сообщения об ошибках понятнее.

Что сделали:

- В **сводке клиента** в админском разделе «Клиенты» появились новые показатели: **среднее за 7 и 3 рабочих дня**, разбивка **данных за период по источникам A / B / C / D** и **график динамики за последние 30 дней**. Источники можно переключать кнопками — сводка пересчитывается по выбранным каналам.
- На **админском дашборде** добавили KPI **«Среднее 7 раб. дн.»** и **«Среднее 3 раб. дн.»** — считаются по рабочим дням (Вт–Сб) от текущей даты.
- Для **проектов** появился **график данных** за выбранный период — доступен и в админском ЛК, и в клиентском. В графике видно динамику по дням и разбивку по источникам.
- В **проектах клиента** (админка) добавили фильтр **«Достигнут дневной лимит»** — показывает проекты, где за выбранный период получено данных не меньше дневного лимита.
- Если проект **достиг 100% дневного лимита**, в общий Telegram уходит уведомление с клиентом, проектом, каналом, лимитом и фактическим объёмом. Повторное уведомление по тому же лимиту не отправляется; при изменении лимита — снова сработает.
- В **Telegram-сигналах остатка тарифа** теперь показывается **имя клиента**, чтобы в общем чате было проще понять, о ком речь.
- Если **сервис поставщика временно недоступен** (в том числе при ошибках шлюза), вместо технического текста показывается понятное сообщение с просьбой повторить операцию позже.

Теперь проще оценивать активность клиентов и проектов по источникам, быстрее замечать проекты на пределе дневного лимита и понятнее реагировать на временные сбои сервиса.
