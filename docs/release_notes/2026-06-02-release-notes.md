## Текст для Telegram заказчика без лишних тех. деталей:

### Release Notes — 02.06.2026

Сегодня улучшили работу с проектами в клиентском ЛК и уведомления по тарифам.

Что сделали:

- В разделе **Проекты** клиентского ЛК добавили удобные кнопки **A / B / C / D**, как на дашборде. С их помощью можно быстро отфильтровать проекты по источникам.
- Одновременно можно выбрать несколько источников. По умолчанию активны все четыре кнопки.
- Если сервис поставщика временно недоступен, вместо длинного технического текста теперь показывается понятное сообщение с просьбой повторить операцию позже.
- При создании, редактировании и массовом изменении проектов номера телефонов теперь можно вводить как с первой цифрой **7**, так и с **8**. Номера с **8** автоматически приводятся к единому формату.
Пример:
89231234567       → 79231234567
8 (923) 123-45-67 → 79231234567
+7 923 123-45-67  → 79231234567
- Добавили понятные Telegram-уведомления о создании тарифа, дополнительных начислениях, списаниях и остатке. Если персональная группа клиента не настроена, уведомления уходят в общий чат.
- Третий сигнал остатка тарифа сделали необязательным. Для персональных уведомлений прогноз срока рассчитывается по активности за последние семь дней.

Теперь клиенту проще переключаться между проектами разных источников, вводить номера телефонов и понимать причины временных ошибок, а уведомления по тарифам стали понятнее и гибче.
