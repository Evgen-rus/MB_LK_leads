# Release Notes — 26.05.2026

## Кратко

Обновили админский раздел **Клиенты**: активные клиенты и архив теперь разделены, а рабочая сводка клиента открывается во всплывающем окне вместо нижнего блока под таблицей.

Изменения касаются только админского ЛК. Backend, API, роли, баланс, тарифы, проекты и клиентский кабинет не менялись.

## Что изменилось

- На странице **Клиенты** появились два отдельных блока:
  - **Активные клиенты**;
  - **Архив**.
- В архив попадают только клиенты со статусом **Работа: Неактивен**.
- Все остальные рабочие статусы остаются в активном списке.
- У активного списка и архива отдельные счётчики, пагинация и итоги.
- Архив можно свернуть и развернуть.
- Состояние архива сохраняется в браузере, поэтому после обновления страницы сохраняется выбранный режим.
- Если клиент переводится в статус **Неактивен**, архив автоматически раскрывается, чтобы админ видел, куда переместилась строка.

## Сводка клиента

- Клик по строке клиента теперь открывает всплывающее окно **Сводка клиента**.
- В сводке отображаются:
  - статусы сбора данных, работы и автоконтроля;
  - быстрые переходы к изменениям клиента, событиям ЧС и проектам;
  - управление тарифами;
  - владелец клиента и переназначение;
  - управление автоконтролем и массовой паузой проектов;
  - показатели клиента: проекты, данные за период, тариф, остаток.
- Сводка закрывается по крестику, клику вне окна и клавише `Esc`.
- Повтор имени клиента, ID и необработанных событий внутри тела сводки убран: эти данные остаются только в шапке окна.

## Карточка клиента

- Кнопка **Карточка** осталась на месте и по-прежнему открывает редактор данных клиента.
- Кнопки **Тариф** и **Перейти в ЛК** также остались доступными в таблице.
- Интерактивные элементы строки не открывают сводку случайно.

## UI и адаптивность

- Стили сводки приведены к единому виду с остальным интерфейсом.
- Бейдж статуса **Работа** стал компактным и сохранил цвет по статусу.
- Select в блоке **Владелец** больше не выглядит как системный браузерный контрол: добавлены общий стиль, скругление, фон и кастомная стрелка.
- На мобильной ширине таблицы сохраняют горизонтальный скролл, а окно сводки адаптируется по ширине и скроллится внутри.

## Технически

- Изменения выполнены на frontend в:
  - `my-app-vite/src/components/AdminClientsScreen.tsx`;
  - `my-app-vite/src/App.css`.
- Backend/API не менялись.
- Миграция БД не нужна.
- Архив считается на frontend по уже существующему полю `workStatus`.
- Agent-режим экрана не менялся: разделение на архив применяется только для админа.

## Проверки

- Проверена production-сборка frontend.
- Проверен lint frontend.
- Ручно проверено:
  - разделение активных клиентов и архива;
  - перенос клиента между списками при смене статуса **Работа**;
  - открытие сводки по клику на строку;
  - работа кнопок **Тариф**, **Карточка**, **Перейти в ЛК**;
  - сворачивание и разворачивание архива;
  - внешний вид сводки на desktop.

## Для чего это сделано

- Чтобы активные клиенты не смешивались с архивными.
- Чтобы ежедневная работа администратора начиналась с актуального списка клиентов.
- Чтобы сводка клиента открывалась рядом с контекстом действия, без длинного скролла вниз страницы.
- Чтобы архив оставался доступным, но не занимал лишнее место, когда он не нужен.
