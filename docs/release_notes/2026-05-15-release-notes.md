# Release Notes — 15.05.2026

## Кратко

Обновили отображение клиентов в админском и агентском кабинетах, чтобы менеджеру было проще быстро понять ситуацию по каждому клиенту.

## Что изменилось

- В таблице клиентов больше нет одного общего статуса клиента.
- Статусы разделены на понятные блоки:
  - **Сбор данных** — показывает, идут ли данные по проектам клиента.
  - **Остаток** — показывает баланс и финансовый сигнал, если клиент близко к лимиту.
  - **Работа** — ручной рабочий статус менеджера.
- Добавили рабочие, переключаемые в ручную статусы:
  - `В работе`
  - `Ждём оплату`
  - `Ждём данные`
  - `На согласовании`
  - `Пауза по клиенту`
  - `Неактивен`
- Рабочий статус можно менять прямо из таблицы.
- В разделе **Агенты** такие же статусы появились в списке клиентов выбранного агента.
- Финансовые сигналы теперь показываются аккуратнее: если у клиента нет тарифа, статус `Долг` не выводится.
- Служебный пользователь `admin` больше не отображается как клиент в таблице клиентов.

## Для чего это сделано

- Чтобы менеджер сразу видел, работает ли сбор данных.
- Чтобы финансовые предупреждения не смешивались с рабочими статусами.
- Чтобы команда могла вести клиента вручную через понятный статус `Работа`.

## Дополнение: админский дашборд

Добавили новый раздел **Дашборд** для администратора.

Он собирает ключевые показатели в одном экране:

- общее количество клиентов;
- количество проектов;
- активные проекты;
- проекты на паузе;
- проекты в статусе `Блокировка оператора`;
- суммарный остаток клиентов;
- количество полученных идентификаций за сегодня, вчера, 7 дней и 30 дней.

## Что показывает дашборд

- Блок **Требует внимания**:
  - клиенты в критичной зоне по остатку;
  - клиенты в зоне риска;
  - клиенты с ранним предупреждением;
  - проекты с блокировкой оператора;
  - непривязанные лиды;
  - ошибки операций по проектам.
- График динамики полученных данных по дням.
- Разбивку данных по источникам `A / B / C / D`.
- Распределение проектов по статусам.
- Топ клиентов по количеству полученных данных.
- Топ клиентов по активным проектам.

## Дополнительно

- Дашборд доступен только администратору.
- После входа администратор попадает в раздел **Дашборд** по умолчанию.
- Данные считаются на backend, чтобы не загружать большие таблицы во frontend.
- Фильтры дашборда сохраняются в браузере.
- Из дашборда можно перейти в существующие разделы ЛК для детальной проверки.
- На самом дашборде нет действий, которые меняют данные: это обзорный экран для контроля ситуации.
