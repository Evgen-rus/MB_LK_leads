# Release Notes — 15.05.2026

## Кратко

Обновили отображение клиентов в админском и агентском кабинетах, чтобы менеджеру было проще быстро понять ситуацию по каждому клиенту.

## Что изменилось

- В таблице клиентов больше нет одного общего статуса клиента.
- Статусы разделены на понятные блоки:
  - **Сбор данных** — показывает, идут ли данные по проектам клиента.
  - **Остаток** — показывает баланс и финансовый сигнал, если клиент близко к лимиту.
  - **Работа** — ручной рабочий статус менеджера.
- Добавили рабочие, переключаемые в ручную статусы:
  - `В работе`
  - `Ждём оплату`
  - `Ждём данные`
  - `На согласовании`
  - `Пауза по клиенту`
  - `Неактивен`
- Рабочий статус можно менять прямо из таблицы.
- В разделе **Агенты** такие же статусы появились в списке клиентов выбранного агента.
- Финансовые сигналы теперь показываются аккуратнее: если у клиента нет тарифа, статус `Долг` не выводится.
- Служебный пользователь `admin` больше не отображается как клиент в таблице клиентов.

## Для чего это сделано

- Чтобы менеджер сразу видел, работает ли сбор данных.
- Чтобы финансовые предупреждения не смешивались с рабочими статусами.
- Чтобы команда могла вести клиента вручную через понятный статус `Работа`.
