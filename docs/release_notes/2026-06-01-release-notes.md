## Текст для Telegram заказчика без лишних тех. деталей:

### Release Notes — 01.06.2026

Сегодня улучшили работу с клиентами и агентами в админском ЛК.

Что сделали:

- В разделе **Клиенты** сводка теперь открывается только по отдельной кнопке **Сводка**. Клик по строке больше не запускает действие случайно.
- Кнопку редактирования данных клиента переименовали в **Изменить**.
- Создание нового тарифа перенесли в блок **Финансы** внутри сводки клиента. Там же осталось управление существующими тарифами.
- В разделе **Агенты** раскрытие списка клиентов теперь выполняется только по кнопке **Клиенты**.
- Для клиентов агента добавили такой же понятный набор действий: **Сводка**, **Изменить**, **ЛК**.
- Сводка клиента агента теперь открывается во всплывающем окне, поэтому не нужно прокручивать страницу вниз.
- Кнопки перехода в личный кабинет сделали компактнее: **ЛК**.

Теперь действия в таблицах выполняются только по понятным кнопкам, а работа с клиентами стала удобнее и предсказуемее.
