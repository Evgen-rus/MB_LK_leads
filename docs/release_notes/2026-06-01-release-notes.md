## Текст для Telegram заказчика без лишних тех. деталей:

### Release Notes — 01.06.2026

Сегодня улучшили работу с клиентами и агентами в админском ЛК, а также клиентский дашборд.

Что сделали:

- В разделе **Клиенты** сводка теперь открывается только по отдельной кнопке **Сводка**. Клик по строке больше не запускает действие случайно.
- Кнопку редактирования данных клиента переименовали в **Изменить**.
- Создание нового тарифа перенесли в блок **Финансы** внутри сводки клиента. Там же осталось управление существующими тарифами.
- В разделе **Агенты** раскрытие списка клиентов теперь выполняется только по кнопке **Клиенты**.
- Для клиентов агента добавили такой же понятный набор действий: **Сводка**, **Изменить**, **ЛК**.
- Сводка клиента агента теперь открывается во всплывающем окне, поэтому не нужно прокручивать страницу вниз.
- Кнопки перехода в личный кабинет сделали компактнее: **ЛК**.
- При создании и редактировании клиента поля **ИНН** и **Телефон** теперь можно оставить пустыми. Также разрешили создавать несколько карточек клиентов с одинаковым ИНН.
- На клиентском дашборде убрали лишние пустоты в блоках **Проекты требуют внимания**, **Топ проектов** и **Последние события**.
- В блоке **Проекты требуют внимания** отображается компактный список из первых шести проектов, а остальные доступны через прокрутку внутри блока.
- В админском и клиентском дашбордах период при открытии теперь автоматически устанавливается с первого числа текущего месяца по сегодняшний день. В выборе дат добавили отдельный вариант **Текущий месяц**, а прежний вариант **Месяц** уточнили как **30 дней**.
- Если администратор поставил проекты клиента на паузу и временно заблокировал их изменение, клиент всё равно может открыть карточку проекта и посмотреть настройки. Редактирование и сохранение в таком режиме недоступны.

Теперь действия в таблицах выполняются только по понятным кнопкам, карточки клиентов заполняются гибче, клиентский дашборд стал компактнее, а настройки временно заблокированных проектов остаются доступными для просмотра.
