# Release Notes — 18.02.2025

## Кратко

- В админском экране **«Клиенты»** добавлено массовое управление сбором данных по клиенту:  
  **«Поставить проекты на паузу» / «Включить проекты ранее на паузе»**.
- Добавлен механизм **снимка массовой паузы**: сохраняются проекты, которые реально были поставлены на паузу.
- Восстановление работает в режиме **best-effort**: успешно восстановленные включаются, проблемные не останавливают операцию.
- Убрана ситуация «залипания» кнопки: при рассинхроне доступно действие  
  **«Поставить проекты на паузу снова»** (с перезаписью снимка).
- Статус **«Сбор данных: Активен / На паузе»** встроен прямо в кнопку (вторая строка с цветным бейджем).
- Блок **«Проекты из последней массовой паузы»** сделан в виде **accordion** (collapsed/expanded) с количеством проектов.

## Где работает

- Админский ЛК, экран **«Клиенты»**, нижняя большая карточка выбранного клиента.
- Backend API и бизнес-логика массовой паузы/восстановления проектов клиента.

## Массовая пауза/восстановление проектов клиента

### Что добавлено

- Новая логика управления сбором данных на уровне клиента:
  - пауза всех активных синхронизированных проектов;
  - восстановление ранее поставленных на паузу по сохранённому снимку.
- Отдельное хранение снимка массовой паузы в БД.
- Подробный результат операций: сколько обновлено, сколько пропущено, сколько ошибок.

### Правила выполнения

- Изменяется только **статус проекта** (`Активен` / `На паузе`).
- Остальные поля проекта не меняются (лимиты, регионы, телефоны, дни и т.д.).
- Проекты со статусом `Удалён` не восстанавливаются.
- Проекты без `provider_project_id` не участвуют в операции.
- При частичных ошибках операция не прерывается (best-effort), показывается сводка.

### Поведение при рассинхроне

- Если часть проектов из снимка уже включена вручную, интерфейс не блокируется:
  - действие восстановления не «зависает»;
  - доступна повторная массовая пауза (**«Поставить проекты на паузу снова»**);
  - снимок перезаписывается актуальным набором успешно поставленных на паузу проектов.

## Изменения в UI/UX

- Кнопка управления сбором данных размещена в панели действий клиента рядом с переходом к проектам.
- Внутри кнопки:
  - основной action-текст;
  - вторая строка со статусом `Сбор данных:` и цветным бейджем.
- Во время выполнения:
  - кнопка блокируется;
  - показывается inline-статус обработки.
- После выполнения:
  - отображается краткая сводка (`выполнено / пропущено / ошибок`);
  - дополнительно показывается toast с деталями.
- Список проектов из снимка оформлен как accordion:
  - заголовок с количеством;
  - раскрытие/сворачивание по клику;
  - отображение статуса каждого проекта.

## Техническая часть

- Добавлены backend endpoint'ы для состояния и действий массовой паузы/восстановления.
- Добавлены новые типы/контракты API на frontend.
- Добавлено хранение снимка массовой паузы в отдельной таблице.

## Польза для заказчика

- Быстрый контроль «сбор включён/на паузе» для клиента в один клик.
- Предсказуемое восстановление после массовой паузы по сохранённому снимку.
- Отсутствие тупикового состояния интерфейса при ручных изменениях статусов.
- Понятная обратная связь администратору по результату операций.
