# Release Notes — 29.04.2026

## Кратко

- В CSV/XLSX-отчётах по идентификациям изменён порядок столбцов и русские заголовки приведены к тому же виду, что и таблицы на сайте.
- Из отчётов удалены технические поля `project_id` и `user_id`.
- Для админа и агента в отчёт добавлена колонка **«Клиент»** только с именем клиента; если имя не заполнено, используется логин.
- В отчётах теперь применяется frontend-совместимое отображение источников: raw-коды `B1` / `B2` / `B3` / `B4` показываются как `A` / `B` / `C` / `D`.

## Что изменено

### Отчёты: порядок и состав столбцов

- **Админский ЛК и агентский ЛК**: `Дата` → `Телефон` → `Канал` → `Источники` → `Проект` → `ext_id` → `Клиент`.
- **Клиентский ЛК**: `Дата` → `Телефон` → `Канал` → `Источники` → `Проект`.
- Заголовки в CSV/XLSX теперь русские: **Дата**, **Телефон**, **Канал**, **Источники**, **Проект**, **Клиент**.
- Поле **Дата** осталось с прежней логикой отчёта: сначала используется дата провайдера `prov_created_at`, если она есть; иначе дата импорта `imported_at`.
- Поле **Проект** теперь содержит только название проекта, без `project_id`.

### Отчёты: отображение источников

- В колонке **Канал** raw-коды источника приводятся к пользовательскому виду: `B1` → `A`, `B2` → `B`, `B3` → `C`, `B4` → `D`.
- В колонках **Источники** и **Проект** такие же коды также отображаются в пользовательском виде, чтобы файл совпадал с таблицей идентификаций в ЛК.
- Raw-значения в БД и API не менялись; изменение касается только выгрузки файла отчёта.

## Технически

- Основное изменение сделано в `backend/app/main.py` в генерации `/leads/export`.
- Подготовка строки отчёта расширена в `backend/app/crud.py`: добавлено имя клиента для колонки **«Клиент»**.
- Для админского отчёта по всем клиентам клиент определяется по владельцу проекта каждой строки.
- Синтаксис backend-файлов проверен командой `python -m py_compile backend/app/main.py backend/app/crud.py`.
