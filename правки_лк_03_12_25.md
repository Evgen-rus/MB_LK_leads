Экран «Клиенты» и «Проекты» — договорённости по логике личного кабинета

1. Как сейчас работает экран «Клиенты»
Сейчас во вкладке «Клиенты»:
При заходе сначала открывается список клиентов.


Пока клиент не выбран, с данными ничего сделать нельзя.


После выбора клиента показывается блок с информацией и изменениями по нему:


видим список изменений (что клиент менял в своих проектах);


можно перейти к его проектам;


можно поставить изменение «в работу» (оператор берёт задачу);


после выполнения — отметить «выполнено», и задача исчезает из списка.


По каждому клиенту:
заходишь, смотришь, что он изменил (например, убрал что-то с сайта),


ставишь «в работу», делаешь нужные действия,


отмечаешь «выполнено».


Также из карточки клиента можно перейти к списку его проектов.

2. Техподдержка
Добавлен блок техподдержки (пока предварительный вариант):
Кнопка/виджет отправляет сообщение в нашу группу в Telegram.


WhatsApp временно настроен так же, как Telegram, потому что статус WhatsApp пока непонятен.


Пользователь отправляет свой номер телефона и кратко формулирует вопрос/задачу.



3. Экран «Проекты» (админский кабинет)
Во вкладке «Проекты» (админская часть):
Отображаются проекты клиентов.


Клиент в своём кабинете видит только свои проекты, без слова «Клиент».


У проекта есть статус:


активен / на паузе / отключён и т.п.


Клиент может сам выключить проект:


зашёл → сменил статус, например, на «на паузе» → нажал «Сохранить» → проект отключился.


Дополнительно обсуждалось:
Возможность менять статус проекта прямо из списка (без лишних переходов) — например, галочкой или переключателем.


Это можно реализовать, чтобы не было «лишних кликов».



4. Календарь и отчёты
Календарь
Календарь уже реализован технически, но данные пока не подгружаются.


Можно выбирать период:


сегодня / вчера / неделя / за период (через выбор дат).


Сейчас используется стандартный браузерный календарь.


При желании его можно заменить на кастомный — вариантов отображения много, можно «слизать» готовый вариант.


Отчёты
Во вкладке отчётов:
Планируется список уже сформированных отчётов:


дата создания;


по каким проектам сделан отчёт.


Дополнительно нужно:


добавить возможность формировать отчёт по конкретному клиенту, а не только скачивать готовые отчёты.



5. Ключевая правка: разделение логики «Клиенты» и «Проекты»
Важно разделить зоны ответственности вкладок:
Вкладка «Клиенты» = дашборд по клиентам
Задача этой вкладки — управление сущностью «клиент», а не работа с изменениями проектов.
Здесь должны быть:
ID клиента


Название клиента


ИНН


Количество проектов


Выбор даты (по умолчанию — «сегодня»):


чтобы видеть, сколько данных пришло сегодня / за неделю / за период


Статусы клиента


Остаток (сколько данных осталось)


Общий объём данных


Кнопка управления:


начислить данные;


списать данные;


изменить тариф;


при необходимости — отключить клиента, поставить на паузу и т.п.


Показатель «сколько пришло сегодня»:


если в фильтре стоит «сегодня» — за сегодня;


если «за неделю» — за неделю и т.д.


Смысл вкладки «Клиенты»:
Быстрый дашборд:


у кого какие остатки;


кто отключен / на паузе;


сколько данных по каждому;


сколько пришло за выбранный период.


Это позволяет:


вовремя дожимать клиентов с маленьким остатком;


менять им тарифы;


включать/выключать клиентов;


понимать общую картину по базе.


Также здесь обсуждалось:
Кнопка с изменениями («Изменения клиента») может служить быстрым переходом в «Проекты»:


если по клиенту есть изменения, можно нажать кнопку → система перекидывает во вкладку «Проекты» с уже проставленными фильтрами (по этому клиенту и по его изменениям).


Вкладка «Проекты» = работа с проектами одного клиента
Задача вкладки «Проекты» — анализ и редактирование проектов конкретного клиента.
Логика:
Если пользователь заходит через вкладку «Проекты»:


При входе поле пустое.


Ничего не показывается, пока не выбран клиент/проект.


Должна быть заметная кнопка «Выберите проект» (или клиента).


После выбора проекта отображается:


статистика по проектам клиента;


сводка;


изменения по проектам;


фильтры: изменён/не изменён и т.п.


Если пользователь переходит из вкладки «Клиенты» по кнопке изменений:


Он уже выбрал клиента, нажал на кнопку изменений.


Его перенаправляет во вкладку «Проекты» с уже установленными фильтрами по этому клиенту и его изменениям.


Это быстрый сценарий: «вижу, что есть изменения → нажал → сразу работаю по ним в проектах».


Важно:
Все изменения по проектам (принять/отклонить изменения клиента, ставить в работу, отмечать выполнено и т.д.) должны обрабатываться во вкладке «Проекты», а не в «Клиентах».


«Клиенты» — только дашборд и управление клиентом/остатками.


«Проекты» — детальная работа с заданиями и изменениями.



6. Итоговое уточнение концепции
«Клиенты» — это:


дашборд по всем клиентам;


остатки;


статусы клиентов;


общий объём и приход данных за период;


управление тарифами и включением/отключением клиента;


быстрый переход к изменениям (который уже открывается в «Проектах» с фильтрами).


«Проекты» — это:


проекты одного выбранного клиента;


статистика по этим проектам;


все изменения, которые сделал клиент;


работа по изменениям (в работу, выполнено, фильтры по изменениям и т.д.);


доступ к сводке и детальному анализу.


Так формируется чёткое разделение:
 вкладка «Клиенты» = управление клиентами и остатками,
 вкладка «Проекты» = работа с конкретными проектами и изменениями внутри них.
