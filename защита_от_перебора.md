CORS защищает от несанкционированного доступа к API с других доменов, но не защищает от **brute force атак** (перебора паролей) на endpoint логина.

## 🚨 **Текущая проблема**

Ваш `/login` endpoint сейчас **полностью открыт** для перебора:

```python
# backend/app/main.py:185-195
@app.post("/login")
def login(payload: dict, db_sess: Session = Depends(get_db)):

        raise HTTPException(status_code=400, detail="login and password are required")
    user = crud.get_user_by_login(db_sess, login_str)
    if not user or not auth.verify_password(password, user.password_hash):
        raise HTTPException(status_code=401, detail="Bad credentials")  # <- Уязвимо!
    token = auth.create_access_token(user.id)
    return {"access_token": token}
```

Злоумышленник может отправлять миллионы запросов с разными паролями — никаких ограничений!

## 🛡️ **Простые решения для защиты от brute force**

### **Вариант 1: Rate Limiting (самый простой)**

Добавим библиотеку `slowapi` в `requirements.txt`:

```txt
# Добавьте в requirements.txt
slowapi==0.1.9
```

И защитим endpoint логина:

```python
# backend/app/main.py
from slowapi import Limiter, _rate_limit_exceeded_handler
from slowapi.util import get_remote_address
from slowapi.errors import RateLimitExceeded

# После создания app
limiter = Limiter(key_func=get_remote_address)
app.state.limiter = limiter
app.add_exception_handler(RateLimitExceeded, _rate_limit_exceeded_handler)

# Защитим логин: максимум 5 попыток в минуту с одного IP
@app.post("/login")
@limiter.limit("5/minute")
def login(payload: dict, db_sess: Session = Depends(get_db)):
    # ... остальной код без изменений
```

### **Вариант 2: Счётчик неудачных попыток в БД (более надёжный)**

Добавим поля в модель User:

```python
# backend/app/models.py
class User(Base):
    # ... существующие поля ...
    login_attempts = Column(Integer, nullable=False, default=0)
    last_attempt_at = Column(DateTime, nullable=True)
    locked_until = Column(DateTime, nullable=True)
```

И логику блокировки в login:

```python
# backend/app/main.py
from datetime import datetime, timedelta

@app.post("/login")
def login(payload: dict, db_sess: Session = Depends(get_db)):
    login_str = str(payload.get("login") or payload.get("username") or "")
    password = str(payload.get("password", ""))
    
    if not login_str or not password:
        raise HTTPException(status_code=400, detail="login and password are required")
    
    user = crud.get_user_by_login(db_sess, login_str)
    if not user:
        raise HTTPException(status_code=401, detail="Bad credentials")
    
    # Проверяем блокировку
    now = datetime.utcnow()
    if user.locked_until and user.locked_until > now:
        remaining = int((user.locked_until - now).total_seconds() / 60)
        raise HTTPException(
            status_code=429, 
            detail=f"Account locked. Try again in {remaining} minutes"
        )
    
    # Проверяем пароль
    if not auth.verify_password(password, user.password_hash):
        # Увеличиваем счётчик неудачных попыток
        user.login_attempts += 1
        user.last_attempt_at = now
        
        # Блокируем после 5 неудачных попыток на 15 минут
        if user.login_attempts >= 5:
            user.locked_until = now + timedelta(minutes=15)
            user.login_attempts = 0  # Сбрасываем после блокировки
        
        db_sess.commit()
        raise HTTPException(status_code=401, detail="Bad credentials")
    
    # Успешный вход - сбрасываем счётчик
    user.login_attempts = 0
    user.locked_until = None
    db_sess.commit()
    
    token = auth.create_access_token(user.id)
    return {"access_token": token}
```

### **Вариант 3: Комбинированный (рекомендую)**

Используйте оба подхода вместе:
- Rate limiting по IP (5 попыток/минуту)
- Счётчик попыток в БД (блокировка аккаунта после 5 неудач)

## 📊 **Сравнение подходов**

| Метод | Сложность | Надёжность | Против чего защищает |
|-------|-----------|------------|----------------------|
| Rate Limiting | ⭐⭐ | ⭐⭐⭐ | DDoS, массовый перебор |
| Счётчик в БД | ⭐⭐⭐ | ⭐⭐⭐⭐ | Целенаправленный перебор одного аккаунта |
| Комбинированный | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | Всё выше + распределённые атаки |
