Список задач по итогам встречи

#### 1. Доработка раздела «Клиенты» (админская часть)

1.1. В сводку по выбранному клиенту добавить кнопки:
* «Начислить идентификации»
* «Списать идентификации»
Реализовать логику на бэкенде и выводить актуальный **остаток идентификаций** в блоке сводки по клиенту.

1.2. Логика расчёта остатка:
**Остаток идентификаций = сумма всех начисленных идентификаций − сумма всех использованных идентификаций по этому клиенту.**

1.3. Отображение отрицательного остатка:
* если **остаток < 0**, значение остатка подсвечивается красным (в нашем фирменном стиле, без ядовитых оттенков);
* под числом остатка текстовым блоком отображается комментарий: **«Долг»**.

#### 2. Раздел «Баланс»
Добавляем такое же правило в баланс:
2.3. В разделе «Баланс» должны отображаться:
* количество приобретённых идентификаций (история покупок/начислений);
* текущий остаток идентификаций;
* даты всех операций с идентификациями.

2.4. Если **текущий остаток идентификаций < 0**:
* значение остатка подсвечивается красным в стиле интерфейса;
* под значением остатка выводится подпись **«Долг»**.
