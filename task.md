# Задачи по итогам тестирования клиентской версии ЛК --> раздел проекты--> модалка Создать проект

Убрать поле тег при создании проекта так как это неактуально сейчас

## Тексты и подсказки
пояснить «Источники данных»: добавить короткое описание, вот пример: Для проекта можно выбрать однго или нескольких поставщиков данных под каждого поставщика автоматически создасться поект с префиксом поставщика

Поле «Список телефонов» переименовать и уточнить смысл: «Телефоны конкурентов/целевых компаний (по одному номеру в строке начинаем строго с 7)» + пример заполнения.
79231234567
74951234567


Для блока регионов добавить явный текст: «Если ничего не выбрано, сбор идет по всей РФ»

Для «Дней сбора/Даты получения» добавить пояснение: что означают галочки, что данные приходят за предыдущий день (пример: «Пн включен → во Вт получите данные за Пн»).

## Интерфейс и логика
В регионах сделать явный режим: переключатель «Включить» / «Исключить», чтобы нельзя было случайно смешать ожидания, и рядом выводить итог: «Вся РФ, исключая: …» или «Только: …».

В момент создания проекта показать объяснение: «Будет создано N проектов по выбранным источникам. Лимит 100/день распределится между ними».

## Баланс и выгрузка
Баланс/минус: в интерфейсе явно показывать, что «в минус» означает долг и что нужно оплатить (с коротким текстом).
