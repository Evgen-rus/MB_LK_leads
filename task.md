# ✅ **Задача 1: История изменений проекта**

### **Краткое описание**

Реализовать для каждого проекта возможность открыть историю изменений.
При клике по кнопке/иконке “История” должно открываться модальное окно со списком изменений.

### **Что отображать**

* дата изменения
* кто изменил (пока можно выводить просто текстом)
* что именно изменилось (краткое описание)

### **Важно**

* Клиент видит только свои изменения
* Админ позже увидит все (но сейчас без разделения)

# ✅ **Задача 2: Вкладка “Отчёты”**

### **Краткое описание**

Сделать отдельный пункт меню **“Отчёты”**, где будет сохраняться история всех созданных отчётов.

### **Функционал**

* Каждый раз, когда пользователь делает “Экспорт отчёта” (как сейчас в “Идентификации”), запись должна появиться во вкладке “Отчёты”.
* В списке отчёта отображать:

  * дата создания
  * проект
  * выбранный период
  * кнопка **Скачать**
* Содержимое отчёта показывать НЕ нужно — только скачивание.

### **UI**

Простой список + кнопка “Скачать”.
