# AGENTS.md

## Контекст и источники истины

- `backend/app/main.py` — точка входа FastAPI; `my-app-vite/src/` — frontend React + Vite.
- Исходный код и его конфигурация — источник истины. Для архитектурного контекста читайте `ARCHITECTURE.md`.
- `README.md` содержит только краткий запуск. Подробные ручные процедуры ищите в `docs/`.

## Работа с проектом

- Backend запускается из корня: `python -m uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000`.
- Frontend запускается из `my-app-vite`: `npm run dev`.
- Для изменений frontend выполняйте из `my-app-vite`: `npm run lint` и `npm run build`.
- Для затронутых пользовательских сценариев запускайте `npm run test:e2e`; конфигурация Playwright поднимает Vite, а сценарии могут требовать доступный backend.
- В проекте нет настроенного backend-тестового раннера; не выдумывайте команду тестов.

## Данные и секреты

- Не добавляйте в Git и не выводите в ответах содержимое `.env`, `credentials/`, логов, дампов, файлов БД, токенов, паролей или персональных данных лидов.
- Используйте только локальные значения окружения; не заменяйте секреты тестовыми в отслеживаемых файлах.

## Документация и кодировка

- Все текстовые файлы сохраняйте в UTF-8 без BOM; кириллицу не транслитерируйте и не заменяйте Unicode-escape.
- Не обновляйте `ARCHITECTURE.md` автоматически: меняйте его только по явному запросу пользователя.
- Обновляйте `README.md` только при изменении краткого запуска. Подробные ручные процессы документируйте отдельными runbook-файлами в `docs/`, если это требуется задачей.
